BioTrack LIMS – Système de traçabilité biopharmaceutique

Développement Web

Application web de gestion de laboratoire inspirée des systèmes LIMS, développée pour assurer le suivi et la traçabilité des lots de production biopharmaceutique. Elle intègre des fonctionnalités de contrôle qualité, de validation des paramètres de bioprocédés et de génération de rapports d'audit.

Technologies

  • HTML / CSS
  • JavaScript
  • LocalStorage
  • Git & GitHub
  • GitHub Pages

Points Clés

  • Développement d'un module de saisie et de suivi des lots de production.
  • Implémentation de règles de validation automatique des paramètres de température et de pH.
  • Création d'un module de transcription ADN vers ARNm avec validation des séquences.
  • Mise en place d'une recherche et de filtres selon le statut de conformité.
  • Sauvegarde des données avec LocalStorage.
  • Génération et exportation de rapports CSV compatibles avec Excel.
